# C3plusplus

The design of cpp11 2: one C++11 compiler built from cpp11 1.28, with the best of
cppparse and compilerpp, that compiles itself. The implementation lives in
`Compiler-Cpp-Optimize`; this repository holds the design and its review.

Read in this order:

| Document | What it is |
| --- | --- |
| `Compiler_Design_Requirements.md` | The requirements, Draft 2 (R-numbers) |
| `Compiler_Design.md` | Draft 1 of the design |
| `Compiler_Design_Review_Fable.md` | Fable 5.1's critical review of Draft 1, with an alternate design |
| `Compiler_Design_Alternate.md` | Opus 5.5's answer to the review: agreed on most, disputed on five points |
| `Compiler_Design_Agreement_Fable.md` | Fable 5.1's round 2: agreement on four conditions |
| `Compiler_Design_Review_Draft25_Fable.md` | Fable 5.1's review of Draft 2.5 and of proposals P1 and P2 |
| `Compiler_Design_Final.md` | **The design**, Draft 2.5: the agreed text, its basis in the three compilers, and the open items |

Draft 2.5 does not yet take in the conditions of the Draft 2.5 review; its
section 15 lists what is still open.
