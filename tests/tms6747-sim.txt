include-streams          writes a file and reads it back: TI's runtime does that over CIO to the host, and sim6747 carries CIO console output but not file I/O (G1, docs/ride50-test-2026-10-06)
template-nontype-numeric TI's rts6740 printf writes "+inf" where the .expected (clang's) has "inf" - cl6x 8.2.2's and 7.4.4's own builds print the same on TI's C6747 simulator
